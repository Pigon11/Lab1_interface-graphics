# Лабораторная работа №1 — Основы проектирования GUI

Программа на Python + PyQt5, демонстрирующая работу с графическим интерфейсом: окно, три кнопки, надпись. При нажатии на кнопку в надписи отображается соответствующее изображение.

## Изображения

В работе используются три типа структурных изображений:

- **Интерферограмма** — результат интерференции волн
- **Дактилограмма** — отпечаток папиллярного узора
- **Кристаллограмма** — структура кристаллической решётки

## Технологии

- Python 3.8
- PyQt5 5.15

## Структура проекта

```
l2discuss/

├── cl1.py                      # вспомогательный модуль (задел под лабу №2)

├── dactilogramma.png           # изображение
├── kristalogramma.PNG          # изображение

├── .gitignore
└── README.md
```

## Запуск

```bash
pip install PyQt5
python main.py
```
